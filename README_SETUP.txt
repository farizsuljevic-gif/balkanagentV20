BALKANAGENT – FLAT VERSION (NO FOLDERS)

All files in this package are in one level, with no folders.

IMPORTANT:
- The public website pages can be uploaded directly through GitHub Upload files.
- cloudflare-backend.js is included only as a backup/reference.
- Cloudflare Pages will NOT automatically run that backend from the root.
- Therefore secure login, registration, database and admin API require the
  original functions/api/[[path]].js folder structure or a separately deployed Worker.

Upload the visible files directly into the root of your GitHub repository.
