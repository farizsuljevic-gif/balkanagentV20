BALKANAGENT — FINAL VERIFIED FLAT GITHUB VERSION

UPLOAD
1. Open the ZIP.
2. Select every file.
3. Upload all files directly to the root of the GitHub repository.
4. Keep index.html in the repository root.

LANGUAGES
Every page includes the same language selector:
- Crnogorski
- English
- Deutsch
- Shqip
- Slovenščina
- Македонски
- Български
- Ελληνικά
- Русский

Translation uses Google Translate on the deployed website, so internet access is required.
The Crnogorski option uses the closest supported South-Slavic translation model and is labelled Crnogorski.
